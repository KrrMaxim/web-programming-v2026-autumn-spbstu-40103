# Лабораторная работа 3

## Задание

4 вариант.

Реализовать функцию `mergeArrays(arr1, arr2)`, которая объединяет два массива,
удаляя дубликаты.

## Реализация

Решение состоит из одного файла `solution.js` с экспортируемой функцией
`mergeArrays`.

Создаётся копия первого массива с помощью `[...arr1]`. Каждый элемент второго
массива `arr2` проверяется на наличие в результате с помощью метода `includes()`
Если элемент ещё не присутствует в результате, он добавляется через `push()`.
Функция возвращает объединённый массив без дубликатов.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
